# CLAUDE.md — 全局施工规范

本文件是本项目对 AI 编程助手（以及人类协作者）的**硬约束**。任何与本文件冲突的代码建议都应视为错误。

## 0. 项目一句话

浏览器内实时渲染的 90 秒 3D 交互短片《雨夜灯塔：失落的信标》。
用户可滚轮前进/后退、可拖拽接管镜头、可现场切换渲染模式。**不是**导出的 MP4。

## 1. 四条硬红线（不可协商）

1. **锁定版本**：three 版本写死为 **0.187.0**（见 §2），禁止 `^` / `~` 浮动版本；优先使用 `three/webgpu` 与 `three/tsl`，禁止混用已废弃的旧版 API 与旧光照单位。
2. **禁止单文件堆砌**：严格按 `scene / camera / shaders / ui` 分目录拆分，单文件超过 400 行必须拆分。
3. **参数集中**：所有可视觉调节的量（雾浓度、雨量、灯塔转速、辉光强度、曝光曲线、拍点时间码）一律抽离到 `src/config.js` 的 `CONFIG`，不得散落在业务代码里。
4. **显存释放**：任何动态销毁的几何体、材质、贴图必须调用 `.dispose()`；帧循环内不得 `new` 几何体/材质。

## 2. 版本锁定

| 依赖 | 锁定版本 | 说明 |
|---|---|---|
| three | **0.187.0** | 精确版本，package.json 中不带 `^` |
| vite | **8.3.8** | 开发服务器与构建 |

- 引擎入口统一用 `three/webgpu`（`WebGPURenderer` + 节点材质），着色器统一用 `three/tsl`。
- **不要**同时混用 `three` 与 `three/webgpu` 两个入口（会重复实例化）。
- TSL 官方仍标注 alpha，小版本 API 会变动 → **禁止**擅自升级 three 版本。

## 3. 坐标系与单位（铁律）

| 工具 | Up 轴 | 正前方 | 单位 |
|---|---|---|---|
| Blender | **+Z** | −Y | 1 unit = 1 m |
| glTF 2.0 | **+Y** | +Z | meters |
| three.js | **+Y** | 相机看向 −Z | 无单位，按米用 |

1. 本项目一律使用 **three.js Y-up 世界坐标**，格式 **(x, h, z)**，`h` 为高度（Y 分量）。
2. **bpy 脚本内按 Blender Z-up 建模**：文档里写的高度 `h` 对应 Blender 的 **Z** 分量，绝不用 y 表示高度。
3. 导出 .glb 时保持导出器默认 **+Y Up** 转换，不手工旋转、不手工改轴。
4. 导出前**应用全部变换**，使对象 scale 读数为 1.0（修改器与倒角宽度按缩放后尺寸计算）。
5. 禁止负缩放（翻转手性、面朝向与法线）；导出前重算法线。
6. 单位按米；场景关键尺寸见 `src/config.js` 与 `src/scene/placeholders.js` 的 `SCENE` 常量。

## 5. CONFIG 常量

全部可调参数集中在 `src/config.js` 的 `CONFIG`，至少覆盖：
信标三通道强度曲线、闪白转场时间码、雨量与飞沫、雾浓度、辉光阈值、滚轮阻尼、slerp 回正时长、像素比上限。

**修改 CONFIG 不允许改动 BEAT_SHEET.md / SHOT_LIST.md 的时间码**；若确需改时间轴，先改文档再改代码。

## 6. 双轨运镜契约

| 轨道 | 覆盖 | 控制点 | 约束 |
|---|---|---|---|
| railInterior | B1–B10 | 11 个（末点为 B11 静态机位） | 连续推进 |
| railStatic | B11 | 0 个 | 固定机位，**禁止**给它加控制点 |
| railFinale | B12–B13 | 3 个（含虚拟终点） | 室外收尾 |

- 轨道在闪白峰值 **t = 0.7889** 处**硬切**，禁止插值过渡。
- 焦段按拍**硬切**，禁止镜头内变焦插值。
- 每拍的机位 = 该拍的「到达构图」，即在 `t = beat.tIn` 处必须精确成立（验收 A3 依赖这一点）。

## 7. 兼容性红线（答辩兜底）

- **必须保留 WebGL2 自动降级**：教室投影仪 / 助教普通浏览器不能黑屏。
- **禁止依赖 compute shader**（仅 WebGPU 后端可用）、禁止 bindless / storage buffer / 特殊纹理格式。
- 体积光、雨、海面等一律同一套 TSL，**禁止**为 WebGPU 单独写第二条渲染路径。
- 曝光 ramp 在 WebGL2 路径必须 `clamp ≤ 3.0`（无 HDR 中间缓冲时防死白）。
- `renderer.setPixelRatio(Math.min(devicePixelRatio, 2))` 锁死。
- 当前后端（WebGPU / WebGL2）必须在 UI 上可见，便于答辩现场自证。

## 8. 交互契约

| 输入 | 行为 |
|---|---|
| 滚轮 / W·S | 沿时间轴带阻尼推进或倒带（`t ∈ [0,1]`） |
| 按住鼠标拖拽 | 偏移观察角度（偏航/俯仰） |
| 松手 | 四元数 **slerp** 在 0.8s 内平滑回正 |
| 空格 | 播放 / 暂停自动推进 |
| 调试面板 | 一键跳转到 13 拍中任意一拍（立即到位，便于与关键帧比对） |

## 9. 分镜与验收

唯一事实源是三份文档，任何代码改动都要能对应到某一拍的时间码：

- `BEAT_SHEET.md` v2.0 —— 4 幕 13 拍、时间码、信标状态机、验收 A1–A13
- `SHOT_LIST.md` —— 逐镜机位 / 焦段 / 轨道 / 帧预算
- `TECH_SPEC.md` —— 渲染路线、资产管线、T0/T1/T2 分层、兼容性红线

验收 A1–A13 见 BEAT_SHEET §6；**A3 构图采样点 = t 0 / 0.20 / 0.4556 / 0.6333 / 0.80 / 1.0**（t=0.7889 是闪白峰值，只用于闪白检查，不作构图采样）。

## 10. 性能预算

1080p 独显 ≥ 60fps / 集成 ≥ 50fps；draw call < 200；后处理通道 ≤ 2（Bloom 半分辨率）；像素比 ≤ 2。

## 11. 禁止项

- 禁止 `^` / `~` 浮动版本；禁止自动升级 three。
- 禁止把分镜数据、颜色常量、时间码硬编码进业务模块。
- 禁止在 Three.js 里用纯代码硬拼复杂建筑模型（灯塔/石阶/透镜等硬表面一律走 Blender → glb）。
- 禁止一次性生成全部资产再统一检查（必须逐个生成、逐个截图验收）。
- 禁止在没有引用图的情况下臆造"参考视频"的视觉设定并当作既定事实。

## 12. 本地运行与验证降级

npm install
npm run dev            # http://localhost:5173
npm run build && npm run preview   # http://localhost:4173
~~~

`http://localhost:4173/?webgl=1`。
也可以在浏览器里禁用 WebGPU（Chrome 打开 `chrome://flags/#enable-unsafe-webgpu` 关闭）后刷新。

预期：页面正常出画，左下角后端标识显示 **WebGL2**，右上角面板同步显示 WebGL2；滚轮推进、拖拽回正、跳转到某拍均可用，且**不出现黑屏或控制台报错**。
